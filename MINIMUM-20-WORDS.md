# Publishing Rule — Minimum 20 Words

1. Enter article headline and article text (minimum **20 words**).
2. Click Publish. If fewer than 20 words, inline guidance appears and password dialog stays closed.
3. When 20+ words are present, Publish opens premium password dialog.
4. Correct admin password is verified by configured Cloudflare Worker. Only confirmed success triggers green tick.

Live publishing still needs deployment/configuration; opening HTML alone does not make public posts.
