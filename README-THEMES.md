# Article themes and design

Articles and article reader share the exact same theme preference key (`nexframe-theme`) as the main portfolio. Choose Midnight, Pearl Light, Rose Love, Royal Violet, Emerald or Sunset on either page; preference carries across the same website origin.

The publishing API / Cloudflare Worker behavior is unchanged. To activate online publishing configure `js/config.js` and deploy the Worker using `SETUP-GITHUB.md`. Do not put a GitHub token or admin password in client-side JavaScript.
