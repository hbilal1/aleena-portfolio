# Gmail Compose Integration

The homepage email icons, Start a Project CTA, and Complaint/Feedback Prepare Email button now open Gmail's web compose window in a new tab with **aleena.postproduction@gmail.com** prefilled.

Visitors must sign into a Gmail account (if needed) and click **Send** themselves. No messages are sent automatically. No database or backend is required.

Gmail URLs support prefilled To/Subject/Body; attached files must be added manually.
